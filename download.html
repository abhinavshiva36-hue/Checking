📖 How to Use

1

Web Version

  1. Click "Open Web App" button above
  2. Click "Request Permission"
  3. Enter your GitHub Personal Access Token
  4. Click "Check All Files" to scan
  5. Download reports in TXT, JSON, or Python format
2

Python Version

  1. Click "Download Python App" button above
  2. Requires: Python 3.6+
  3. Run: python abhinav_detector.py
  4. Or: python abhinav_detector.py /path -a
  5. Reports saved as JSON and TXT

⚙️ Python App Commands

python abhinav_detector.py Scan current directory
python abhinav_detector.py /path/to/scan Scan specific directory
python abhinav_detector.py -a Auto-save JSON and TXT reports
python abhinav_detector.py -q Quiet mode (no console output)
python abhinav_detector.py -j report.json Save JSON report
python abhinav_detector.py -t report.txt Save text report
