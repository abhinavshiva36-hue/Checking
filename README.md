# File Checker App

A web application that checks for illegal/suspicious files in your repository, with specific focus on Free Fire Max and other unwanted files.

## Features

- 📋 Request file permission to scan your repository
- 🔍 Scan all files in the repository
- ⚠️ Detect illegal/suspicious files (especially Free Fire Max related)
- 📊 Display file details including name and activity
- 📥 Download app option to save your report

## How to Use

1. Open the app in your browser
2. Click "Request Permission" to grant access to your repository
3. Click "Check Files" to start scanning
4. Review the results showing any illegal files found
5. Download the report if needed

## Tech Stack

- Frontend: HTML, CSS, JavaScript
- Backend: Node.js/Express (optional)
- GitHub API integration for file scanning

## Installation

```bash
npm install
npm start
```

Then open `http://localhost:3000` in your browser.
